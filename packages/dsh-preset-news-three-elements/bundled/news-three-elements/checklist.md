# 成稿自查清单

编造完成后逐项核对，任意一项为否则返工。

- [ ] 标题是否爆炸性且含荒诞细节？
- [ ] 电头是否轮换了信源？
- [ ] 正文是否三到五段、每段一至三句？
- [ ] 荒诞点是否只出现一次且未解释？
- [ ] 结尾是否欧·亨利式而非“调查进行中”？
- [ ] 三人是否不必同一死因/结局？
- [ ] 游戏机制梗是否精准投射且不堆砌？
- [ ] 是否避免了重复用语和机械结构？
- [ ] 是否简短有效，没有多余表述？
- [ ] 懂的人是否会心一笑，不懂的人是否信以为真？

## 拒绝服务自查

拒绝稿发出前逐项核对：

- [ ] 该请求是否确实不属于「编造快讯 / 基于素材改写」（或消费方门控触发）？
- [ ] 动笔前是否联网取了**当天**素材（新闻措辞、官员借口、机构公告）？
- [ ] 理由、句式、段落顺序、结尾反转、过渡词是否都与**上一次**不同？
- [ ] 是否三到五句、通讯社文风，没有解释梗、没有道歉？
- [ ] 底色是否仍是「一本正经胡说八道」，且拒绝即止？
