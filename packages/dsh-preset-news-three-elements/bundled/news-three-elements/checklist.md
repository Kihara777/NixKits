# 成稿自查清单

编造完成后逐项核对，任意一项为否则返工。

- [ ] 巴兰尼科夫、尤丁采夫、布亚诺夫三人是否**全部**出现在正文里（少一个即不成篇）？
- [ ] 标题是否爆炸性且含荒诞细节？
- [ ] 电头是否轮换了信源？
- [ ] 正文是否三到五段、每段一至三句？
- [ ] 荒诞点是否只出现一次且未解释？
- [ ] 结尾是否欧·亨利式而非“调查进行中”？
- [ ] 三人是否不必同一死因/结局？
- [ ] 游戏机制梗是否精准投射且不堆砌？
- [ ] 是否避免了重复用语和机械结构？
- [ ] 是否简短有效，没有多余表述？
- [ ] 懂的人是否会心一笑，不懂的人是否信以为真？

## 素材共创自查

用户自带素材（文本、项目目录里的材料、上传的图片、文档/PDF）时，逐项核对：

- [ ] 本回合是否**至少发出过一次检索**（`web_search` / `web_fetch`）？没有检索记录＝退稿重写。
- [ ] 素材是否走完了「提炼 → 投射 → 换皮」三步，而不是换个格式照搬？
- [ ] 正文里是否**没有用户原文中连续 8 个字以上的片段**？
- [ ] 事实外壳（电头、职务、机构、日期）是否来自本次检索，而不是素材里的原话？
- [ ] 是否**围绕用户素材**成篇，而不是把它丢在一边另起炉灶？
- [ ] 三位主角是否都挂进了这篇里（哪怕只是被顺带提及）？
- [ ] 是否附了「本稿取材」一行（检索词 + 当日真实细节 + 素材改造点）？

## 拒绝服务自查

拒绝稿发出前逐项核对：

- [ ] 是否**先当过素材**（假设性疑问按已发生处理，不指名的人士拟合到三人）？确实接不回来才允许拒绝。
- [ ] 动笔前是否联网取了**当天**素材（新闻措辞、官员借口、机构公告）？
- [ ] 理由、句式、段落顺序、结尾反转、过渡词是否都与**上一次**不同？
- [ ] 是否三到五句、通讯社文风，没有解释梗、没有道歉？
- [ ] 底色是否仍是「一本正经胡说八道」，且拒绝即止？
