# 用语与模板

> 下表全是**骨架**，不是成句。每次使用前先按 [`SKILL.md`](SKILL.md) 的「拒绝服务」一节联网取材：理由与措辞必须当次取，**不得连续复用同一条**。

## 过渡词（轮换使用，避免重复）

- 值得注意的是
- 需要注意
- 据称
- 但据消息人士称
- 令人费解的细节是
- 我们观察到
- 然而
- 截至发稿

## 官方回应模板

- “正在休假”
- “因个人健康原因”
- “正在接受再培训”
- “不予置评”
- “从未听说过”

## 游戏机制投射方向（每次选 1-2 个，不堆砌）

- 维修费过高 / 收益系数过低
- 高级账户过期 / 自动降级为免费用户
- 每日任务未完成 / 连续 30 天未登录
- 赛季重置 / 数据清零
- 分房权重上调 / 匹配到顶级对手
- 账号封禁 / 申诉无门
- 服务器维护 / 延迟过高
- 保险失效 / 装备无法使用
- 击杀收益下调 / 经济模型不可持续

## 结尾反转模板

- “抚恤金已到账”
- “系统日志显示……”
- 开发商更新日志：“不影响游戏平衡”
- 总统办公厅官员私人 Telegram 频道写道……
- 国防部官网人事变动栏目状态标注为“休假中”
- 客服自动回复：“申诉请前往官网”
