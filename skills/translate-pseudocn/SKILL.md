# 伪中国语翻译

为 NixKits 文档体系提供 pcn（伪中国语）语言，通过日语→中文语序转换与假名剥离实现。设计目的为文档撰写技能的模块化语言后端。

## 自动发现契约

write-project-docs 和 write-maintenance-log 通过扫描 `skills/translate-*/SKILL.md` frontmatter 自动发现本技能：

| 字段 | 值 | 用途 |
|------|-----|------|
| `language_code` | `pcn` | 目录名 `docs/pcn/`、文件扩展名 `*.pcn.md`、for 循环迭代 |
| `display_name` | `偽中国語` | 语言自称（统一用于所有文档中该语言的入口标签） |
| `base_language` | `ja` | 伪中国语转换的源语言（日语文本） |

## 触发场景

- 由 write-project-docs 自动发现并调用（按 `translate-*` 命名约定扫描 `skills/translate-*/`）

## 语言：pcn（伪中国语）

### 原理

伪中国语是一种伪本地化技巧：取日语文本，剥离全部平假名/片假名，将日语句法（SOV）转换为中文语序（SVO），使用中文标点符号。结果视觉上近似中文但语法保持日语汉字结构。

**示例**：
```
このソフトウェアは、NixOSの設定を管理します。
```
→
```
此软件 NixOS 之設定 管理。
```

### 替换规则

1. **去除假名** — 剥离**所有假名**（平假名あ-ん + 片假名ア-ン）。
   片假名外来语通过内置词典映射为伪中国语形式（如 `バージョン`→`版本`、`アップストリーム`→上游）。
   未在词典中的片假名被剥离。平假名尾缀一并剥离（如 `食べる` → `食`）。
2. **语序调整** — SOV（主语-宾语-动词）→ SVO（主语-动词-宾语）
3. **助词替换**：
   - `は`（主题）→ 无（或转换为中文语序）
   - `が`（主语）→ 无
   - `を`（宾语）→ 无（SOV 转换为 SVO 时自然移除）
   - `の`（所属）→ `之`
   - `と`（并列）→ `与`
   - `に`（方向/目标）→ `於` / `向`
   - `で`（手段/场所）→ `以` / `於`
   - `から`（起点）→ `自`
   - `まで`（终点）→ `至`
5. **标点转换** — 日文标点 `、` `。` → 中文标点 `，` `。`
6. **保留内容** — 数字、URL、英文缩写、符号不翻译
7. **代码块保护**（⚠️ 关键——必须用 ` ``` ` 边界精确识别）：
   - Nix 代码块：仅翻译 `#` 注释，表达式/标识符/属性路径完全不动
   - Bash 代码块：全部内容保持原样（命令行、参数、子命令均不转换）
   - 环境变量名不替换
   - 执行层面：先提取代码块，仅对非代码块区域应用伪中国语转换规则

## 注意事项

- 伪中国语是视觉装饰性伪本地化，不追求翻译准确性
- 语言切换器中的语言名称不作本地化——各语言使用自身 display_name，不翻译（如 `English` 保持 `English`，`日本語` 保持 `日本語`）
- 技术术语和代码块保持原样
- Nix 表达式不进行转换
- **pcn 文档切换器生成规则**（从日文源）：
  - `[中文]`→保留链接、`[English]`→保留链接
  - `日本語`（纯文本）→ `[日本語](ja路径)` 加链接（不再是当前语言）
  - `[ｶﾀﾘｯｼｭ]`→保留链接
  - `[偽中国語](pcn路径)`→ `偽中国語` 纯文本（自身标签）
  - **必须用 bash 逐个文件精确构造**，不可依赖 sed 模式匹配替换（易丢失入口）
