# agent-self-maintenance (Skill)

[中文](../../zh/skills/agent-self-maintenance.md) | [English](../../en/skills/agent-self-maintenance.md) | 日本語  | [偽中国語](../../pcn/skills/agent-self-maintenance.md)

> 失敗しうる五つの小さな仕組みで、AI コーディングアシスタントが自分の記憶を長期保守できるようにする。

## 基本情報

| 項目 | 値 |
|------|-----|
| 種別 | Coding Agent Skill |
| パス | `skills/agent-self-maintenance/SKILL.md` |
| 対象 | `journal/` と自己検査スクリプトを持つ任意のリポジトリ |

## 五つの仕組み

| 仕組み | 判据 | 境界 |
|---|---|---|
| 日記ゲート | コミットがあり当日の日記が未変更 → 一度だけ通知 | 未設定なら静かに |
| 開始時の照合 | 受領書 / 日記 / 事実を読む；ok / red / stale を混ぜない | 「一度も走っていない」を言う |
| 事実検査 | 各事実に探針；`検証不能` は第三の状態 | データはリポジトリに残す |
| 自己観察 | 彼女が言った / 私が測った / 不明、を分けて記録 | 条目に日付と証拠 |
| 自己検査受領書 | 五状態、`ok` だけが静か | 受領書はコミットしない |

## データの帰属

仕組みは移植可能、**データは移さない**：事実条目・観察条目・閾値は各リポジトリのもの。

## 参考実装

dsh の本機の私有プリセットが五つの仕組みの完全な実装である。
