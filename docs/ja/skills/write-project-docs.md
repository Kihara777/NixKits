# write-project-docs (Skill)

[中文](../../zh/skills/write-project-docs.md) | [English](../../en/skills/write-project-docs.md) | [日本語](write-project-docs.md)

> 任意のプロジェクトに対して NixKits スタイルの完全な多言語ドキュメントシステムを生成します — モジュールドキュメント、スキルドキュメント、分類 README。

## 基本信息

| 项目 | 值 |
|------|-----|
| 类型 | Coding Agent Skill |
| 路径 | `skills/write-project-docs/SKILL.md` |

## 功能

- **プロジェクト評価**：モジュール/パッケージ定義を読み取り、メタデータを抽出
- **モジュール分類**：機能別にグループ化（インフラ/サービス/プロキシ/ナビゲーション/静的リンク）
- **ディレクトリ作成**：`docs/{zh,en,ja}/skills/` 構造を自動生成
- **README 作成**：言語切替行 + カテゴリテーブル + ドキュメントリンク
- **モジュールドキュメント**：情報テーブル + インストール + 参照 + 使用方法（NixKits テンプレート）
- **スキルドキュメント**：情報テーブル + 機能リスト + トリガー条件
- **並列化**：大規模プロジェクトではサブエージェントを並列実行
- **検証**：ファイル数、リンクチェック、用語の一貫性

## 使用

ユーザーが「ドキュメントを作成」または「NixKits スタイルでドキュメントを生成」を要求したときにアクティベートされます。

## 規約

- ゼロ修辞、テーブル優先、完全なコードブロック
- 技術用語は英語のまま
- 警告は `> **⚠️**` ブロッククォート
- 3 言語の独立したファイル、相対パスの言語切替行
