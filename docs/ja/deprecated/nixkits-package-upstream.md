# nixkits-package-upstream スキル名（廃止）

[中文](../../zh/deprecated/nixkits-package-upstream.md) | [English](../../en/deprecated/nixkits-package-upstream.md) | 日本語  | [偽中国語](../../pcn/deprecated/nixkits-package-upstream.md)

[← 廃止プロジェクト索引](../../../DEPRECATED.md)

**状態**：スキル名を廃止（2026-10-20）
**旧位置**：`skills/nixkits-package-upstream/`
**現状**：ファイルは**純粋な監査適配層**として残り、先頭に廃止告知がある。汎用手法は `upstream-audit` へ移動済み。

## なぜ廃止したか

上流貢献スキルは二層に分割された：

| 層 | 内容 | 場所 |
|---|---|---|
| `upstream-audit` | 評価・要求の監査・dry-run —— **読取専用、dry-run まで** | 本リポジトリ |
| 私有提出層 | fork / ブランチ / commit / push / PR / レビュー対応 | 展開側の私有プリセット（本リポジトリは配布しない） |

旧名は「監査」と「提出」の両方を暗示していたが、新しい構造では適配層の監査責務しか持たない ——
**責務より広い名前は、次の誤用の入口になる**。

## 移行

- 汎用の監査には `upstream-audit` を使う；
- 提出は環境側の権限ある層を使う（本リポジトリは提供しない）；
- 旧名はスキル一覧・登録・プリセットには現れない；`MAINTENANCE.*` の履歴は旧名を保つ（履歴は書き換えない）。

## 一つの判据

**名前の廃止はファイルの削除ではない。** 内容は適配層として残っているが、**書き込み操作はもう含まない**
—— それは権限を要する層へ移された。廃止されたのは「一つの名前が二つのことを約束する」という形である。
